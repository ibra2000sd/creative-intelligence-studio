# Creative Intelligence Studio — نظرة تنفيذية

## ما هو؟

إضافة (Plugin) لـ Claude Code تحوّل وصف مشروع إبداعي بلغة عادية إلى مخرجات هندسية حقيقية: هوية بصرية، موقع تسويقي، بوابة عملاء، تطبيق جوال، صور وأصول بصرية، حركة وتفاعل، وتجربة ثلاثية الأبعاد. كل هذه المخرجات تُشتق من ملف واحد اسمه **«الحمض النووي للتجربة» (Experience DNA)** يحدد الألوان والخطوط والمسافات والحركة والمواد، فلا يخرج كل جزء بشكل مختلف عن الآخر.

## ما الذي بُني فعلاً؟

| المكوّن | الحالة |
|---|---|
| إضافة Claude Code قابلة للتثبيت: 17 مهارة، وكيلان، خطّاف واحد (Hook) | منفّذة وتجتاز `claude plugin validate` |
| واجهة أوامر `creative-studio` من 28 أمراً، بلا أي اعتماديات في نواتها | منفّذة ومختبرة |
| 15 عقد بيانات (JSON Schema) بإصدارات | منفّذة ومختبرة |
| محرك الهوية: شعار متّجه قابل للتحرير، أيقونات، تطبيقات، دليل هوية PDF | منفّذ ومختبر |
| مصنع الصور: محرك محلي إجرائي، فحص أبعاد وألوان وتكرار، سجل مصادر | منفّذ ومختبر |
| موقع تسويقي بالعربية والإنجليزية مع سرد مرتبط بالتمرير | منفّذ ومختبر في المتصفح |
| بوابة عملاء (React) بمخطط متحرك وجداول ونماذج وحالات خطأ | منفّذة ومختبرة في المتصفح |
| تطبيق جوال (Expo / React Native) بإيماءات وحركة | منفّذ؛ الاختبارات وحزم iOS وAndroid ناجحة؛ البناء الأصلي غير منفّذ على هذا الجهاز |
| مشهد ثلاثي الأبعاد تفاعلي بنموذج GLB مولَّد ومحسَّن ومتحقق منه | منفّذ ومختبر |
| نظام جودة آلي: وظائف، مظهر، إتاحة، حركة، أداء، أمن | منفّذ، وله اختبارات تثبت أنه يكشف العيوب المزروعة |
| إدارة تعديلات العميل وحزمة التسليم | منفّذة ومختبرة |

## ما الذي يميّزه؟

1. **مصدر واحد للحقيقة.** أي تغيير في الهوية يمر عبر الـ DNA ثم ينتقل إلى كل المخرجات بأمر مزامنة، وأمر `dna consistency` يثبت بالمقارنة الحرفية أن كل مخرج مطابق.
2. **لا إنجاز وهمي.** المهمة لا تُعتبر منتهية إلا إذا وُجدت ملفاتها وطابقت عقدها. الفحص الذي يتعذر تشغيله يُسجَّل «محجوباً» لا «ناجحاً».
3. **القرار للإنسان.** بوابات الاعتماد (الموجز، الاتجاه الفني، النظام، الجودة، الاستلام) لا يعتمدها إلا شخص مسمّى؛ والنظام يرفض أسماء مثل agent أو claude.
4. **الحركة قرار لا زينة.** محرك الحركة قد يجيب «لا تحرّك»، ويختار أخف تقنية تؤدي الغرض.
5. **الخصوصية والتكلفة.** لا شيء يغادر الجهاز إلا بما يسمح به الموجز، وكل نداء مدفوع يُحجز من ميزانية المشروع قبل تنفيذه.

## حدود يجب معرفتها

- لم يُنفَّذ بناء أصلي لتطبيق iOS أو Android على هذا الجهاز لغياب Xcode وAndroid SDK. تم التحقق من حزم JavaScript ومن تشغيل الكود نفسه في المتصفح.
- مزوّد الصور الخارجي (OpenAI) جُرِّب فعلياً مرة واحدة بموافقة المالك (صورة واحدة بجودة منخفضة، بتكلفة تقديرية 0.006 دولار) ونجحت في جميع فحوص الجودة؛ أما التعديل والخلفيات الشفافة والجودات الأعلى فما زالت مختبرة على بديل محلي فقط.
- أُجريت المراجعة الإبداعية المستقلة ست مرات بواسطة وكيل المراجعة في الإضافة (نموذج، لا إنسان)، مع إصلاحات بين الجولات: وجدت الجولة الأولى مشكلة مانعة و13 مشكلة كبيرة، ووجدت كل جولة من الثالثة إلى السادسة بين 7 و8 مشكلات كبيرة بعد إصلاح معظم ما سبقها. أوصت الجولات كلها بـ«المراجعة»، وتوقّفت الجولات بعد السادسة لأن الحكم على جاهزية العمل للعميل قرار بشري. أما بوابتا الجودة والاستلام فتحتاجان إلى أشخاص حقيقيين وما زالتا مفتوحتين.
- لا يُجرى بحث علامات تجارية، ولا تُنتَج ملفات طباعة CMYK أو قوالب تغليف.
- الفحوص الآلية أدلة وليست موافقة عميل، وأرقام الأداء «مختبرية» من هذا الجهاز وليست بيانات مستخدمين.

القائمة الكاملة في `docs/limitations.md`، ونتائج آخر تشغيل في `docs/release-report.md`.

## العميل التجريبي

«هالدورا» شركة خيالية لبطاريات المنازل. اتجاهها الفني «دفتر ضوء النهار»: يوم البيت يُروى على شكل قوس تسير عليه الشمس، ويظهر هذا القوس في الشعار، وفي سرد الموقع، وفي مخطط البوابة، وفي قرص التطبيق، وفي الضوء على المنتج ثلاثي الأبعاد.
