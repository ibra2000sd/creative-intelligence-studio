# Mobile app (Expo)

React Native app built with Expo Router, Reanimated and Gesture Handler. Colours, type, spacing and motion come from `src/dna/` and are regenerated by `creative-studio mobile sync`; do not edit those files by hand.

## Run

```bash
npm install
npm run typecheck
npm test
npx expo start
```

## Verify

```bash
npm run export:native   # production JS bundles for iOS and Android (Hermes bytecode)
npm run export:web      # web build of the same code, used by `creative-studio test mobile`
```

`creative-studio test mobile` runs the type check, Jest, both exports, and drives the web build in a browser: onboarding swipe, tabs, device detail, slider drag, offline banner and language switch.

## What that does not cover

The web build proves the JavaScript, navigation, state and gesture maths. It does not prove native rendering, native gesture arbitration, haptics, safe areas on real hardware, VoiceOver or TalkBack. Before release, build and test on devices:

```bash
npx expo run:ios       # needs macOS with Xcode
npx expo run:android   # needs the Android SDK and an emulator or device
```

Store builds additionally need an Apple signing identity and an Android keystore.

## Right-to-left

Arabic switches copy, typeface and layout direction at once on iOS and the web through the root `direction` style. On Android, a complete mirror also requires `I18nManager.forceRTL(true)` followed by an app restart.

## Adapting

`src/logic.ts`, `src/i18n.ts` and the screens under `app/` contain example energy-domain content. Replace them together; keep the components in `src/components/` and the theme plumbing.
